Using TechNav

For students, visitors, and anyone navigating Tech.
Maps cover the basement through the fourth floor.

01

Choose a start and destination

Search a room number or select a listed location. Start from the main entrance or another location in the building.

02

Follow each instruction

The map shows the route and next turn. Use Back and Next as you move. An elevator-only option avoids stairs.

Approved hallway photos appear where available.

03

Report a map issue

Report incorrect directions, mark a room’s entrance, or submit a hallway photo. Submissions are reviewed before publication.

Project information

TechNav is a Northwestern CS392 course prototype. It runs in a mobile browser and is free to use.

Prototype limitations

Maps and photos may be incomplete, routes may contain errors, and distances are estimates. The project may not be maintained past the quarter.

GitHub repository

Data collection

Reports
Submitted text, floor, map pin, and route context—including the starting point, destination, and step—are stored for review.
Feedback
Feedback submitted in the app and an optional reply email are stored privately for authorized TechNav reviewers.
Photos
Uploads are resized to a maximum of 1600 px and re-encoded as JPEG. Original metadata is removed.
Usage
The production app uses Firebase Analytics to understand usage.
Review & hosting
Authorized reviewers read submissions. Approved photos and entrance corrections are public. Google Firebase provides hosting, database, and authentication services. The project does not sell this data.
